# Project conventions

- Start every session with `docs/HANDOFF.md` (current state, which session does what, open work) and update it when that changes.

- Keep Ink & Gold styling scoped to brand-specific tokens and the shared Logo; preserve independent article typography and layout tokens to avoid broad visual changes.
- Keep original uploaded brand artwork and the brand font in CDN asset pointers; render derived public logo, manifest, touch and share files at their established URLs so existing clients remain compatible.
